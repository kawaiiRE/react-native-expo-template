# Security policy

## Supported versions

Security fixes are applied to the latest commit on `main`. Applications created from this template own their dependency upgrades, signing credentials, backend rules, and store-release security posture.

## Reporting a vulnerability

Use GitHub's private **Report a vulnerability** flow in the repository Security tab. Do not include credentials, personal data, exploit details, or production URLs in a public issue.

Include the affected revision, impact, reproduction steps, and any suggested mitigation. Please allow time to validate and coordinate a fix before public disclosure.

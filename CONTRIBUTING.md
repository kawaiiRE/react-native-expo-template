# Contributing

Thanks for improving the template. Keep changes generic, focused, and independently deployable.

1. Create a branch from `main`.
2. Install with `corepack yarn install --immutable`.
3. Keep contracts, services, hooks, stores, screens, and tests synchronized.
4. Run `corepack yarn check` before opening a pull request.
5. Describe behavior changes, native permission changes, and manual device verification in the pull request.

Do not commit credentials, `.env`, generated native projects, build output, or copied production data. Add optional native SDKs only with a real product requirement and document their platform setup.
